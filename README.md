# 🪔 Festival of Lights — An Interactive Diwali Experience

> **More than a celebration. An experience brought to life through light, colour, creativity and code.**

A visually immersive, interactive Diwali-themed web experience that transforms the traditional festival of lights into a digital celebration.

The journey begins with an unlit, handcrafted 3D diya. Users interact with it to ignite the flame, triggering a cinematic animation that opens into a vibrant festive world filled with interactive games, digital fireworks and creative experiences.

## ✨ The Experience

**From a single flame to an entire celebration.**

The website is designed as an interactive journey rather than a conventional festival landing page.

- 🪔 **Light the Diya:** An interactive 3D diya with continuous rotation, handcrafted visual details and a cinematic ignition sequence.
- 🎨 **Hybrid Animation:** A combination of 3D environments and 2D illustrated effects, inspired by modern comic-book animation techniques.
- 🎆 **Firecracker Simulator:** Experiment with digital simulations of traditional Indian fireworks.
- 🎮 **Diwali Mini-Games:** Play festive games designed to bring an element of fun and interaction.
- 🎉 **Interactive Fireworks:** Experience colourful particle explosions, animated trails and spectacular fireworks displays.
- 💌 **Share the Joy:** Create personalised Diwali greetings and share festive wishes.

## 🚀 Project Vision

The idea behind this project is simple:

**What if lighting a diya could open an entire digital Diwali celebration?**

Instead of presenting users with a static greeting, the project turns a familiar cultural tradition into an interactive experience.

It combines traditional festive elements with modern web development, creative animation and playful interactions to make the celebration more engaging.
